# CineCanvas 教学优先重构路线（P0–P3）

> Date: 2026-07-28
> 定位转变：从「AI 生成教案 + 拖滑块」的工具原型，转为**以教学设计为核心**的
> 三层调色能力养成产品。AI 退居到它可靠的位置（诊断、解说、风格适配），
> 教学质量由确定性的策划内容保证。
> 配套铁律见 [`.cursor/rules/engine-protection.mdc`](../../.cursor/rules/engine-protection.mdc)。

---

## 0. 目标用户与三层能力

有摄影/审美基础、但不懂参数含义、不明调色顺序、只会套滤镜的新手。

- **第一层 · 机制**：每个参数控制什么，彼此区别。
- **第二层 · 操作**：调色顺序，如何精确控制（曲线怎么拉、颜色怎么还原）。
- **第三层 · 品味**：看懂并复现电影/大师风格，会设计创意蒙版。

## 1. 体验诊断（本次实测结论）

- **「拖进区间就完事」**：阴影拖到区间内打勾，故意拖到 95（严重过头）
  只是勾消失，无负反馈；全程无 before/after、无直方图，用户学不到区别。
- **参数区别感知不到**：同图曝光 +40 与阴影 +95 截图几乎无法区分——
  用用户随手拍的照片教参数机制，天然不利，必须用精选诊断图。
- **引擎响应偏弱**：`uExposure` 只映射到 ±1.5 档，曝光 +40 变化很轻微
  （见 `pipeline.ts`）。反馈是教学地基，需回归。
- **可靠性隐患**：首次分析 Gemini 结构化教案降级，降级文案还引用产品里
  不存在的「色彩分级/污点修复」；刷新页面会话全丢（zustand 未持久化）。

## 2. 指导原则

1. **追加式开发**：新功能不改现有 10 滑块管线（见铁律文件）。
2. **教学内容确定性优先**：关卡用固定诊断图 + 隐藏配方，不依赖模型每次输出。
3. **物理隔离**：教学功能走 `src/pages/learn/*` 新路由，不碰 `/workspace`。
4. **每阶段可独立验证、可 revert**。

## 3. 引擎能力分组（决定实现难度与分期）

| 组 | 能力 | 参数 | 架构影响 | 风险 |
|----|------|------|----------|------|
| **A · 逐像素点操作** | 当前单 shader 直接扩展 | 现有 10 项 + 曲线(LUT) + HSL + 色调分离 | 加 uniform / 256×1 LUT 纹理，追加式 | 低 |
| **B · 邻域/多 pass** | 需新架构 | 清晰度、纹理、锐化、去朦胧、降噪 | RenderTexture + 可分离高斯模糊 | 高 |

分水岭：**是否需要看周围像素**。曲线/HSL 只看单像素 → A 组；
清晰度家族本质是不同半径的非锐化蒙版 → 必须 B 组。

## 4. 辨析关卡清单（第一层，已定稿 5 组）

每组一关，固定诊断图 + 影响区域可视化 + 直方图联动 + A/B 辨认题。

1. **曝光 vs 白色 vs 高光**（都让亮部变亮：整体平移 / 推最亮端点 / 只提已亮区内部）
2. **阴影 vs 黑色**（暗部：救暗部内容 / 压最黑下限）
3. **对比度 vs 清晰度 vs 去朦胧**（力量感：全局两端 / 中间调局部反差 / 去大气灰雾）
   —— 清晰度/去朦胧属 B 组引擎，此关放到 P2。
4. **自然饱和度 vs 饱和度**（挑着提 / 雨露均沾，肤色保护）
5. **色温 vs 色调**（黄-蓝轴 / 绿-品红轴）

> 第 1、2、4、5 关只需 A 组引擎，落在 P1；第 3 关需 B 组，落在 P2。

## 5. 「匹配目标图」练习闭环规格（第二层）

- **布局规则**：两张图沿**图片短边方向**排列。
  - 横图（宽）→ 目标图 / 用户图**上下堆叠**，控制台在右。
  - 竖图（高）→ 两图**左右并排**，控制台在下或右。
  - 实现：读图片宽高比一个三元判断自动切换。
- **对比视图（主路径只要两种）**：
  1. 并排（target ｜ yours）
  2. 闪回叠放（同位置点击切换，眨眼比对，最易发现差异）
- **评分按图像差异**（降采样像素 / 直方图 diff），非滑块数值——
  允许殊途同归，自然引出「曝光+20 ≈ 白色+40」的讨论。评分可在后台算 diff，**不必**用热力图 UI。
- 完成后揭示参考配方，AI 解说「你的解法 vs 参考解法」。

**默认不做；非主路径：差异热力图**

伪彩色标出「你的图 vs 目标图」像素偏差。额外认知负荷（用户要学一套伪彩色语义），而闪回已覆盖大部分「找出差异」场景。  
**P0 / P1 主路径均不做。** 禁止写成「P0 必做」或默认开启的第三种视图。仅当实测用户反复卡在「差一点却找不到在哪」时，才可考虑作为**默认折叠的可选高级视图**——须产品明确点名，agent 不要自行加回。

## 6. 分阶段任务与验收

### P0 · 教学地基（不碰引擎数学，纯追加 UI + 引擎回归）

**任务**
- before/after 闪回对比组件（点击/按住切换）——已落地于 `/learn/lab`
- **直方图 = 参数示波器（教学化，P0.2a）**，不是专业诊断仪：
  - 自解释坐标：黑→白渐变条 + 常驻大白话 + 「?」展开
  - 幽灵基线：抓起滑块时冻结淡色轮廓，对照看山怎么动
  - 实时文字翻译：整句描述「山如何运动 → 照片会怎样」（含方向）
  - 可选一行纯文字诊断（无照片像素遮罩）
- 影响区域可视化：复用 shader 亮度遮罩，把当前滑块影响权重伪彩色叠加
- 引擎响应回归：复核 `pipeline.ts` 各滑块映射强度，调到「±50 = 明显但不过火」

**明确不做（非主路径）：**

1. **直方图 ↔ 照片像素联动**（原设想的 TonalRangeOverlay）  
   拖滑块已能看画面变化 + 文字翻译足够；遮罩缩放易错位、ROI 低、做了难删。  
2. **差异热力图**  
   额外认知负荷；主路径用并排 + 闪回即可。评分可用后台 diff，不必可视化热力。

禁止把以上两项写成「暂缓 / 二期再做 / P0 必做 / optional later 默许加回」。除非产品明确点名。

**验收**
- [x] before/after 闪回在 `/learn/lab` 可用
- [x] 直方图示波器：渐变轴 / 幽灵 / 翻译句（用户已验收 P0.2）
- [ ] 影响区域可视化可用
- [ ] 曝光 ±50 肉眼变化明显；`npm run verify:tonal` 仍全绿
- [ ] `lint` + `build` 通过
- [ ] **没有**照片像素高亮遮罩 / TonalRangeOverlay / 差异热力图主路径 UI

### P1 · A 组引擎扩展 + 第一、二层关卡

**任务**
- 单 shader 追加**曲线**：控制点 → 单调三次样条 → 256×1 LUT 纹理 → shader 查表
  （默认 identity）。先亮度曲线，再 RGB 分通道。
- 单 shader 追加 **HSL**：8 色相通道 × (色相/饱和度/明度)，色相距离加权（默认 no-op）
- 同步 `tonalMath.ts`，扩展 `verify:tonal` 覆盖曲线/HSL 的 no-op 与单调性
- 第一层关卡 1、2、4、5（固定诊断图 + 可视化 + 辨认题）
- 第二层「匹配目标图」闭环（含图像差异评分 + 并排/闪回双视图 + 横竖布局；无热力图）
- 曲线/HSL 专项关卡：S 曲线=手动对比度、抬黑点=褪色、黄通道饱和度=「减黄还蓝」
- 会话持久化（zustand persist），避免刷新丢图

**验收**
- [ ] 曲线/HSL 默认值下渲染与扩展前逐像素一致（no-op 证明追加式无副作用）
- [ ] `verify:tonal` 扩展项全绿；`lint` + `build` 通过
- [ ] 4 个辨析关卡 + 匹配闭环可玩通，评分按图像差异
- [ ] 横图/竖图布局自动正确切换

### P2 · B 组多 pass 引擎 + 清晰度家族

**任务**
- 引入 RenderTexture + 可分离高斯模糊 pass（引擎架构扩建，独立于单 shader）
- 实现清晰度（大半径 UM + 中间调遮罩）、纹理（中半径）、锐化（小半径）
- 去朦胧（近似：强化全局对比 + 饱和，或暗通道先验，视成本定）
- 第一层关卡 3（对比度 vs 清晰度 vs 去朦胧）+ 清晰度 vs 纹理 vs 锐化关卡

**验收**
- [ ] 多 pass 管线不影响 A 组既有输出（关闭 B 组时逐像素一致）
- [ ] 清晰度/纹理/锐化默认 0 = no-op
- [ ] 清晰度家族关卡可玩通
- [ ] `lint` + `build` 通过；性能在预览分辨率下拖动流畅

### P3 · 第三层电影风格库（品味）

**任务**
- `films.ts`：每卡 = 参考剧照 + 人工「读片」拆解 + 人工校准量化配方
  （≥4 个非零滑块，对齐 `MIN_GRADING_STEPS`）
- 接 `generateFilmSteps`：AI 拿固定配方 + 用户图做差异化适配 + 解说
- 读片工具：提取剧照主色板 / 简化示波器，教用户「看出」风格
- 首页「Select Your Film」拼贴入口
- （可选）颜色统计迁移生成「目标预览图」，回接 P1 匹配闭环让用户手动逼近

**验收**
- [ ] ≥3 张风格卡，配方人工校准过、效果不发灰（`/debug/compare` 目测）
- [ ] AI 适配输出通过 zod 校验；降级文案只引用产品内真实存在的功能
- [ ] 风格库 → 工作台流程打通

## 7. 里程碑依赖图

```
P0 教学地基 ──┬──▶ P1 A组引擎 + 关卡1/2/4/5 + 匹配闭环
              │
              └──▶ P2 B组引擎 + 关卡3 + 清晰度家族
                          │
P1 ───────────────────────┴──▶ P3 电影风格库（复用匹配闭环）
```

P0 是一切的前提（闪回对比 / 直方图示波器被后续复用；不含差异热力图）。
P1 与 P2 引擎组互不依赖，可并行；但关卡内容依赖各自引擎组先就位。
P3 依赖 P1 的匹配闭环。
